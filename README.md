# ОКТО Converter v0.2

Статическое веб-приложение для подготовки больших текстовых документов к последующему импорту в базу знаний ОКТО-3 AI.

## Возможности
- Локальное чтение UTF-8 TXT, MD, CSV и JSON (без загрузки исходников на сервер).
- Деление текста на части с сохранением порядка и всех символов; по возможности по границам строк.
- Настраиваемый максимальный размер JSON-части: 16–8192 КиБ.
- ZIP-пакет (без сжатия): `manifest.json` и `doc-XXXX/part-YYYYY.json`.
- SHA-256 исходного текста в manifest для проверки обратной сборки.
- Пакетная загрузка, ошибки и предпросмотр.

## Важно
- PDF, DOCX, XLSX, OCR и семантическое деление пока **не реализованы**.
- ZIP использует STORE без сжатия и не поддерживает ZIP64; максимальный ZIP меньше 4 ГиБ, до 65535 элементов. Ограничение RAM браузера может быть существенно ниже.
- JSON исходного файла валидируется, но его структура не анализируется. CSV пока не разбирается по ячейкам.
- Разделение по строкам может разорвать длинный логический блок; таблицы не распознаются.
- Формат `okto-package-v1` — **предварительный**; бот ОКТО-3 AI пока не умеет автоматически импортировать этот пакет.
- Для обратной сборки объединяйте `text` частей в порядке `part_index` и сверяйте SHA-256 с `manifest.json`.
- Веб-приложение требует безопасного контекста (HTTPS) для Web Crypto SHA-256; GitHub Pages подходит.
