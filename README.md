# ОКТО Converter v0.3 (экспериментальная версия)

Веб-конвертер документов в пронумерованные JSON-части и ZIP-пакет для будущего импортёра ОКТО-3 AI.

## Поддержка
- TXT, MD, CSV, JSON: текст UTF-8; JSON валидируется.
- DOCX: текст через Mammoth, табличные строки в виде `|`-разделённых ячеек; изображения и сложные объединения ячеек не сохраняются.
- XLSX: значения листов через SheetJS, табуляция между ячейками; формулы, стили, изображения не сохраняются.
- PDF: текстовый слой через PDF.js с маркерами страниц; **без OCR**, координатных таблиц и изображений.

Для новых форматов библиотеки загружаются с CDN при первом использовании; интернет необходим. Исходные документы обрабатываются в браузере, но не загружаются на наш сервер.

## ZIP
- `manifest.json`: источник, тип, количество частей, SHA-256 извлечённого текста, предупреждения.
- `doc-0001/part-00001.json`: последовательные текстовые фрагменты.
- Размер части 16–8192 КиБ; по возможности деление по границам строк.
- ZIP STORE без сжатия, без ZIP64, до 4 ГиБ и 65535 элементов; практический предел зависит от памяти браузера.
- Формат `okto-package-v1` предварительный; импортёр Telegram-бота пока не реализован.

## Проверка
Новые парсеры PDF/DOCX/XLSX не прошли сквозное тестирование в браузере; проверьте на копиях документов. Особое внимание таблицам, изображениям, переносам и полноте данных.
