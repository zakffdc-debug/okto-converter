# ОКТО Converter

Статическое веб-приложение для локальной конвертации документов в форматы, пригодные для импорта в ОКТО-3 AI.

## v0.1

- Поддерживается чтение UTF-8 TXT, MD, CSV и JSON.
- Экспорт JSON (schema: okto-document-v1), Markdown и TXT.
- Пакетная загрузка, очередь результатов, предпросмотр, отдельное и массовое скачивание.
- Обработка только в браузере. Файлы не загружаются на сервер.

**Ограничения:** CSV сохраняется как исходный текст, без анализа таблиц; JSON нормализуется в текст. PDF, DOCX, XLSX, изображения и OCR пока не реализованы. Браузер может запрашивать разрешение на несколько скачиваний. Массовый экспорт пока создаёт отдельные файлы, а не ZIP.

## Запуск

Откройте `index.html` через локальный статический сервер или включите GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). После публикации адрес будет `https://zakffdc-debug.github.io/okto-converter/`.

## Принципы

Не объявлять неподдерживаемые форматы успешно обработанными. Следующие этапы: ZIP-экспорт, PDF.js, Mammoth (DOCX), SheetJS (XLSX), OCR с контролем качества и сохранение структуры источника.
